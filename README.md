# Mr. Nook

An audiobook app for your own books. A small robot with a book for a screen
keeps your place, remembers when the sleep timer went off, and lets two people
share one library with separate progress.

Works as a web app on phone and desktop. Downloads for offline listening,
sleep timer with chapter end, bookmarks, and a shared wishlist.

Currently in private testing. Source code is not public.
